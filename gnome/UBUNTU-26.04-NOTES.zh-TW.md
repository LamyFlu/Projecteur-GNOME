# Ubuntu 26.04／GNOME 50 相容版本

使用者操作請見 [繁體中文 README](../README.zh-TW.md)；
架構、建置及除錯請見 [開發說明](README.md)。

本機確認環境為 Ubuntu 26.04、GNOME Shell 50.1、Wayland、
Logitech Spotlight USB（`046d:c53e`）及 OnlyOffice 全螢幕簡報。
使用者已確認紅點、游標隱藏、翻頁與停留秒數等現有功能正常。

GNOME daemon 保留 Projecteur 的裝置處理，透過 D-Bus 通知 Shell 擴充顯示紅點。
紅點可見期間暫停全螢幕 unredirect，結束後恢復；全螢幕應用程式鎖定游標時，
使用簡報器的相對位移補足紅點移動。

隱藏游標前保留指標焦點，確保 Mutter 能更新游標圖像。紅點消失、daemon 離線或
擴充停用時，會恢復游標並釋放此擴充自己的焦點與顯示控制。

停止移動後的停留時間可設為 0.1–30 秒，預設 3 秒，從最後一次位移計算。
這是指示鍵放開事件的近似處理：持續按住按鍵而不移動也會開始計時。

中文系統（包含簡體中文語系）使用繁體中文介面，其餘語系使用英文。
安裝只需在專案根目錄執行 `./install.sh`，再重新連接簡報器並登出登入。
更新會保留既有設定。
